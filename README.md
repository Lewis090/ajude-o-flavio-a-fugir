# ✈️ Ajude o Flávio a fugir

Jogo de navegador feito em JavaScript puro (HTML + Canvas).

Ajude o Flávio a decolar da **Argentina**, cruzar o **Equador** e chegar até a **Flórida**, desviando dos aviões da "Polícia Federal" que tentam impedir a fuga. Qualquer semelhança com pessoas reais é mera coincidência: o personagem é fictício.

## 🎮 Como jogar

- **Computador:** setas do teclado ou WASD para pilotar. Espaço ou Enter para começar.
- **Celular:** arraste o dedo na tela.
- Você tem 3 vidas. Pegue a estrela ★ para ganhar 5 segundos de escudo.
- Chegue ao fim da barra de progresso para vencer.
